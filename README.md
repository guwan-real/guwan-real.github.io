# Personal Homepage

Astro-powered personal homepage for `https://guwan-real.github.io/`.

## Local Development

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## CS Review Appendix

Computer science revision and browser-local practice are available at `/appendix/cs-review/`.
