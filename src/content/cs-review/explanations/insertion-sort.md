## 排序不只是把数字变小到大

排序按关键字重新安排记录。升序 / 降序要先说明；一条记录还可能有姓名等其他字段，不能只移动关键字而忘了其对应数据。**内部排序**通常假定待排数据可放入内存；外部排序则更关注内存放不下时的读写与归并。

用 `[2甲,2乙,1]` 说明**稳定性**：甲和乙的关键字同为 2，原来甲在乙前。排完若仍是 `[1,2甲,2乙]`，保持了相等键的相对次序；若变成 `[1,2乙,2甲]`，就不稳定。稳定不是“每次输出都一样”，也不表示“永不出错”。

## 直接插入：维护一个已经排好的前缀

像整理手里的牌：每次拿下一个数，与前面已排好的部分比较，给它腾出合适位置。对 `[5,2,4,1]`：

| 轮次 | 插入的数 | 怎样移动 | 轮后状态 |
| --- | --- | --- | --- |
| 初始 | 5 视为已排前缀 | 无 | [5,2,4,1] |
| 1 | 2 | 5 后移，2 放最前 | [2,5,4,1] |
| 2 | 4 | 5 后移，4 放 2 后 | [2,4,5,1] |
| 3 | 1 | 5、4、2 依次后移 | [1,2,4,5] |

典型实现只移动**严格大于**待插入键的元素，相等时不跨越，因此稳定。逆序时要移动约 $n(n-1)/2$ 个元素，最坏平方阶；已经有序时，每轮很快确认位置，最好可线性。额外空间通常为常数。

折半插入可减少寻找位置的比较，但数组后移仍可能平方级。不能把“用二分定位”直接当整个排序降为 $O(n\log n)$。

## 冒泡：相邻比较，把极值送到一端

本节规定从左向右、遇逆序相邻元素就交换，因此每轮把剩余最大值送到右端。

```text
初始：       [5,2,4,1]
第一轮过程： [2,5,4,1] → [2,4,5,1] → [2,4,1,5]
第二轮结束： [2,1,4,5]
第三轮结束： [1,2,4,5]
```

如果某整轮没有交换，可以提前结束，所以带提前终止的典型实现最好为 $O(n)$。只在严格逆序时交换，可保持稳定。若改成从右向左，第一轮送到左端的就可能是最小值；“一轮后状态”题必须先读方向。

## 简单选择：选最小，再与边界交换

同样从 `[5,2,4,1]` 开始，第一轮找出最小值 1，与首项 5 交换，立即得到 `[1,2,4,5]`。但标准简单选择仍会在剩余区间寻找最小值；不能因为这组数巧合已经排好，就把该算法一般时间写为线性。

典型比较次数固定为 $(n-1)+(n-2)+...+1=n(n-1)/2$，交换次数通常少于冒泡。它**不稳定**：`[2甲,2乙,1]` 第一轮交换后成为 `[1,2乙,2甲]`，两个 2 已反转。

## 希尔：先把相距较远的元素做插入

希尔排序按增量 gap 把位置分组，在各组内做插入，再逐步缩小 gap，最后 gap=1。例如下标 0、2、4 属于 gap=2 的一组，下标 1、3、5 属于另一组；它们不是原数组中连续切出的两半。

远距离移动有助于先减少大范围逆序，使最后插入更轻松。复杂度强烈依赖增量序列，不能脱离具体 gap 一律记成同一个精确指数；典型实现不稳定，额外空间可为常数。

## 快速排序：先分区，之后再递归

核心是选一个枢轴 pivot，把区间分成与它相比大小不同的部分，再对子区间处理。不同分区法的中间状态不同，“一趟快排”必须说明枢轴与交换规则。

本例用末元素 5 为枢轴、Lomuto 分区，小于等于枢轴的元素移入左前缀：

```text
[7,2,6,3,5]
2 进入左侧 → [2,7,6,3,5]
3 进入左侧 → [2,3,6,7,5]
枢轴放到边界 → [2,3,5,7,6]
```

这只是**一次分区**，右侧 7、6 还未排好。不能因为枢轴已确定位置就认为整列完成排序。

分区较均衡时递归有约 log n 层，每层总工作约 n，平均常为 $O(n\log n)$；连续极端分割可达 $O(n^2)$。典型原地分区不稳定；递归栈平均 $O(\log n)$，简单实现最坏可达 $O(n)$，不是“原地就完全不要栈”。

## 堆排序：每次取堆顶极值

升序堆排常建立大根堆：父结点不小于孩子，根是当前最大值。把根和未排区最后一个元素交换，缩小堆，再让新的根下沉恢复堆性质。**堆只保证父子局部次序，不保证数组从头到尾有序。**

例如大根堆 `[9,7,8,3,2]`，把 9 换到末尾后，未排区暂为 `[2,7,8,3]`；下沉 2，与较大孩子 8 交换，得 `[8,7,2,3]`，尾部 9 已就位。随后重复。

自底向上建堆可为 $O(n)$，每次取顶并调整约 $O(\log n)$，全部排序为 $O(n\log n)$；迭代调整的额外空间可为常数，典型堆排不稳定。把 n 个结点全部乘树高，只得到不紧的 $O(n\log n)$ 上界。实际多数结点靠近叶子，下沉距离很短；需要走更高距离的结点数逐层减少，累加工作量可为线性。

## 归并：两边有序，再用双指针合并

归并排序先把问题拆小，再把两个有序段合为一个有序段。例如合并 `[2,5]` 与 `[1,4]`：比较两头取 1，再取 2、4，最后复制剩下的 5，得到 `[1,2,4,5]`。

每层合并总工作线性，常规二路归并有对数层，时间为 $O(n\log n)$。数组实现通常需 $O(n)$ 辅助空间。遇相等键先取左段，可以保持原来的先后，因而常见实现稳定。不要把“把两半接在一起”当成已合并有序。

## 计数与基数：不只靠两两比较

计数排序适用于键来自大小可控制的整数范围，统计每种键出现次数，再按位置输出；典型时间 $O(n+k)$，k 是键范围大小，空间也与范围有关。若键范围远大于 n，额外表可能不划算。

LSD 基数排序从低位到高位，每一位都需用稳定方式整理。对 `[21,13,12,23]`：按个位稳定分配收集得 `[21,12,13,23]`；再按十位稳定整理得 `[12,13,21,23]`。若第二轮随意打乱同十位元素，前一轮建立的低位顺序就会被破坏。

d 位、每位 r 个桶的常用复杂度写为 $O(d(n+r))$。比较排序的一般下界在相应模型下为 $\Omega(n\log n)$，不直接限制利用整数位、范围等额外结构的排序；计数 / 基数没有“违反数学下界”。

## 最后用一张表整理，不要只背表

以下均指常见教学实现；稳定性可以通过修改实现改变，额外空间不算输入本身。

| 算法 | 平均 / 最坏时间 | 常见额外空间 | 常见稳定性 |
| --- | --- | --- | --- |
| 直接插入 | 平方 / 平方，基本有序时可更好 | 常数 | 稳定 |
| 冒泡 | 平方 / 平方，带提前结束最好线性 | 常数 | 稳定 |
| 简单选择 | 平方 / 平方 | 常数 | 不稳定 |
| 希尔 | 随增量序列变化 | 常数 | 不稳定 |
| 快速 | n log n / 平方 | 平均 log n 栈 | 不稳定 |
| 堆 | n log n / n log n | 常数（迭代调整） | 不稳定 |
| 二路归并 | n log n / n log n | n | 稳定 |
| LSD 基数 | d(n+r)，取决于位数与桶 | n+r | 每位稳定时稳定 |

做一趟结果题先写算法规则，再逐次移动；做稳定性题给相同键贴上甲乙标记；做复杂度题区分比较、移动和递归空间。能手推前面的四个数，才更容易把表中的结论记牢。

## 资料题型补充：认中间状态，要找已经保证的部分

排序识别题不能只看“前面有几个数恰好递增”，要看算法每轮保证什么。升序直接插入在两轮后，前三个元素构成有序前缀，但它们不一定处于全局最终位置；简单选择每轮固定一个最小元素；从左向右冒泡每轮固定一个最大元素到末端；标准堆排序每次取最大堆顶，也逐步形成最终有序后缀。

例如原序列 `[9,8,7,6,5,4,3]` 做直接插入：第一轮为 `[8,9,7,6,5,4,3]`，第二轮为 `[7,8,9,6,5,4,3]`。它有有序前缀，却没有把全局最小值3固定到前面。再看 `[2,3,4,1]`，最后一轮插入1之前，前缀2、3、4已局部有序，但最终结果是1、2、3、4，所以四个元素此时都不在最终位置。局部有序与全局归位不能互换。

## 资料题型补充：LSD 基数排序为什么必须稳定

对十进制三位记录 `305、117、201、412、109`，先按个位稳定分配、按桶号收集，得到 `201、412、305、117、109`。第二轮按十位，十位为0的记录必须保留上一轮形成的次序 `201、305、109`，十位为1的保留 `412、117`，因此第二轮结果为 `201、305、109、412、117`。它按“后两位”已有序，但还没有按百位完成全局排序。

若十位相同就随意倒置，上一轮建立的个位次序会被破坏。所谓稳定，并非只在普通比较排序中有意义，LSD正是依赖每一轮稳定，才把较高位与已处理低位的顺序逐步组合起来。位数不足时如何补零、是否有负数或不同进制，都要按题设处理。

快速排序的辅助空间也需写条件：普通双递归实现，划分较均衡时栈深为Θ(log n)，若每轮只有0与n−1的极端划分，栈深可为Θ(n)。先递归左边还是右边不会凭空改变需要处理的子问题总量；若采用“只递归较小部分、较大部分用循环继续”的特定改写，则可以限制同时活跃的调用深度。这个改写与“交换两句普通递归调用次序”不同。不能将资料中未说明条件的O(log n)当成所有输入下的最坏保证。
