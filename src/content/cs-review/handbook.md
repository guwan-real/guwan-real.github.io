## 0. 应试导航与题型识别

- **看到“次数、复杂度、趟数”**：先确定算法的具体实现、数据规模、最好/最坏/平均情形，再计算。
- **看到“地址、容量、位宽、块号”**：把单位统一到 bit/byte，写出地址位数与偏移位数，区分容量扩展与位宽扩展。
- **看到“补码、溢出、移位”**：先判定位宽与有无符号，再转真值、计算、检验可表示范围。
- **看到“页号、帧号、缺页”**：地址分解、页表/TLB 查找、置换顺序逐次模拟。
- **看到“SQL、范式、调度”**：明确键与函数依赖，或画冲突图/等待图；不要凭直觉判断。
- **看到“子网、路由、窗口”**：转二进制或统一字节/秒，明确哪个字段、哪个层次。
- **看到“树、图”**：先明确存储结构、遍历方向、是否有权/有向，再选算法。
- **看到“软件工程”**：按生命周期（需求→设计→实现→测试→交付维护）找题目所处阶段。

# 第一篇 数据结构与算法【两者】

## 1. 数据结构基本概念、算法分析（国网 1；南网数据结构 1）

**原理**：数据结构 = 逻辑结构（集合、线性、树形、图状）+ 存储结构（顺序、链式、索引、散列）+ 数据运算。抽象数据类型 ADT 描述操作的语义，不规定实现；算法应满足有穷、确定、可行、输入和输出等性质。

**怎么做**
- 时间复杂度：数基本操作的执行次数，去掉常数与低阶项；单循环看边界，嵌套循环看总和，递归写递推式。
- `for(i=1;i<n;i*=2)` → `O(log n)`；双层 `i<n,j<i` → `O(n²)`；分治 `T(n)=2T(n/2)+O(n)` → `O(n log n)`。
- 主定理常用：`T(n)=aT(n/b)+Θ(n^d)`，比较 `a` 与 `b^d`，边界情形通常 `Θ(n^d log n)`（需满足主定理条件）。
- 空间复杂度看**辅助空间峰值**，递归要计算调用栈深度；原始输入是否计入取决于题目约定。
- `O` 为渐近上界，`Ω` 下界，`Θ` 紧确界；不要把“大 O”自动理解成平均复杂度。

**易错**：按语句行数而不是执行次数计；把递归的时间和栈空间混为一谈。

## 2. 线性表、数组、链表、集合（国网 2；南网数据结构 2、3）

**原理**：顺序表连续存储、支持 `O(1)` 随机访问，但中间插删需移动 `O(n)`；链表指针连接，找到节点后插删 `O(1)`，按下标访问 `O(n)`。链表查找前驱或节点本身仍可能花 `O(n)`。

**怎么做**
- 顺序表按位置插入，统计需要移动的元素数量；注意插入位置从 0 还是从 1 编号。
- 单链表删除 `p` 后继：`p.next=p.next.next`；删除给定节点一般须知道前驱（或使用特定技巧）。
- 双链表插入/删除同时修改左右指针；循环链表尾节点指回头节点，带头节点的空表并非头指针为 `NULL`。
- 数组行优先存储：二维 `A[m][n]`，元素宽 `w`，`LOC(A[i][j])=base+(i*n+j)*w`（0 下标）；列优先则 `base+(j*m+i)*w`。
- 集合的交并差：若无序集合，用哈希平均可接近线性；有序集合可双指针合并。

**易错**：顺序存储 ≠ 一定“有序”；链表插删 O(1) 的前提是插删位置已定位。

## 3. 栈、队列与递归（国网 3；南网数据结构 2）

**原理**：栈 LIFO、队列 FIFO；递归以调用栈保存返回地址与局部状态。

**怎么做**
- 合法出栈序列：模拟入栈/出栈；入栈顺序 `1,2,3` 不可能先出 `3,1,2`（3 出后 2 挡在 1 上方）。
- 循环队列常用“牺牲一格”方案：队满 `(rear+1)%N==front`，队空 `rear==front`，有效容量 `N-1`；若额外计数，则可存满 N 格。
- 栈表达式转换：中缀→后缀用运算符栈；后缀求值遇数字入栈、运算符取出两个操作数（减除要注意顺序）。
- 括号匹配、DFS、撤销操作用栈；层序遍历、BFS、任务缓冲用队列。
- 向**低地址增长**且 SP 指向**已有栈顶**：PUSH 先 `SP-=元素大小` 再写；POP 先读再增加 SP。若 SP 指向下一空位，顺序相反；向高地址增长则增减方向相反。

**易错**：只看“向上/向下”不看地址定义；队列 front/rear 的指向约定不同，空满条件随之变化。

## 4. 数组压缩存储与字符串（国网 4）

**原理**：利用对称、三角、带状、稀疏矩阵结构减少冗余；串的匹配可复用已有匹配信息。

**怎么做**
- 对称矩阵 `n×n` 只存一半加对角线，共 `n(n+1)/2` 项；用行优先下三角（`i>=j`、0 下标）存储，映射 `k=i(i+1)/2+j`，上三角元素 `A[i][j]=A[j][i]`。
- 三对角矩阵只有主对角及两侧非零，非零元最多 `3n-2`。
- 稀疏矩阵用三元组 `(row,col,val)` 或 CSR；矩阵转置需交换坐标并按需要重新排序。
- 朴素模式匹配最坏 `O(nm)`；KMP 在失配时利用模式串前后缀重合长度，不回退主串指针，`O(n+m)`；求 `next/LPS` 要看教材从 0 还是 1 开始。

**易错**：公式若采用 1 下标，要整体变换，不能只改一个位置。

## 5. 树、二叉树及相关结构（国网 5；南网数据结构 2）

**原理**：树的每个非根节点有唯一父节点；二叉树左右子树有次序。满二叉树、完全二叉树、二叉搜索树 BST、堆不是同一个概念。

**怎么做**
- 二叉树第 `i` 层最多 `2^(i-1)` 个节点（根为第一层）；高度 `h` 最多 `2^h-1` 个节点。
- 非空二叉树度数：`n0=n2+1`（叶子数比双分支节点数多 1）。
- 完全二叉树数组 1 下标：父节点 `⌊i/2⌋`，左右孩子 `2i,2i+1`；0 下标变为 `(i-1)//2,2i+1,2i+2`。
- 遍历：先序 根左右；中序 左根右；后序 左右根；层序 BFS。给定先序+中序或后序+中序可唯一恢复**节点值互异**的二叉树，单独先序+后序通常不够。
- BST 中序是有序序列；AVL 平衡因子为左、右子树高度差，绝对值 ≤1，通过 LL/RR/LR/RL 旋转修复。
- 哈夫曼树：反复合并最小两个权值，求带权路径长度 `WPL=Σw_i l_i`；编码需满足前缀码。
- 树与森林转换：左孩子右兄弟表示法。

**易错**：完全二叉树不必所有叶子同层；BST 最坏可能退化为链，查找 `O(n)`。

## 6. 图（国网 6；南网数据结构 4）

**原理**：图 `G=(V,E)` 可有向/无向、有权/无权；遍历与最短路、最小生成树、拓扑排序是不同问题。

**怎么做**
- 无向图度数之和 `2|E|`；有向图入度总和 = 出度总和 = `|E|`。
- 邻接矩阵空间 `O(V²)`，适合稠密图；邻接表 `O(V+E)`，适合稀疏图。
- DFS 用递归/栈；BFS 用队列，在**无权图**中求边数最少的路径。
- 最小生成树：无向连通带权图；Prim 每次扩展当前树的最小跨边，Kruskal 按边权排序用并查集防环。
- 最短路：Dijkstra 需边权非负；Bellman–Ford 可处理负边并检测可达负环；Floyd–Warshall 求任意两点最短路，`O(V³)`。
- 拓扑排序：只适用于 DAG；反复取入度 0 节点，若无法处理全部节点，则有环；结果可能不唯一。
- 关键路径：在 AOE 网中计算事件最早/最迟发生时间，零时差活动是关键活动。
- 并查集：`find` 查代表元、`union` 合并，路径压缩+按秩合并使均摊效率接近常数。

**易错**：把最短路径树当最小生成树；用 Dijkstra 处理负权边。

## 7. 查找、索引与散列（国网 7；南网数据结构 3、5）

**原理**：查找性能由数据组织方式决定；索引用额外空间换查找效率，哈希用函数将关键字映射到桶。

**怎么做**
- 顺序查找：无序 `O(n)`；有序顺序表可提前终止。
- 二分查找：要求**随机访问且按键有序**；每次 `mid=(low+high)//2`；成功的比较次数取决于元素位置，失败时需检查边界越过。常见闭区间实现在 `n=16` 时失败最多 5 次。
- 折半判定树高约 `⌊log₂n⌋+1`（非空层数），题目要区分成功/失败 ASL、比较次数/判定次数。
- 分块查找：块内可无序、块间按最大关键字有序；先索引查块，再块内扫描。
- B 树：多路平衡搜索树，节点内多个键、所有叶在同层；B+ 树数据记录常位于叶层，叶节点链表有利范围查询。
- 哈希：`h(key)=key mod p`；冲突处理有链地址、线性探测、二次探测、双重散列；装填因子 `α=记录数/表长`，越大冲突通常越多。
- 线性探测 `h,h+1,h+2,...`（模表长）；删除不能随意清空导致探测链断裂，常用删除标记。

**易错**：哈希平均常接近 `O(1)`，但不保证最坏；二分要求数组有序，不适合一般单链表。

## 8. 内部排序（国网 8；南网数据结构 5）

**原理**：稳定是指**相同关键字元素的原相对次序保持不变**；比较排序的一般下界为 `Ω(n log n)`（决策树模型）。

| 算法 | 平均时间 | 最坏 | 额外空间（典型实现） | 稳定 |
|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | 是 |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 |
| 简单选择 | O(n²) | O(n²) | O(1) | 否 |
| 希尔 | 与增量相关 | 常见增量可 O(n²) | O(1) | 否 |
| 快速 | O(n log n) | O(n²) | 平均 O(log n) 栈 | 否 |
| 堆 | O(n log n) | O(n log n) | O(1) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定分配时是 |

**怎么做**
- 插入：维护已排序前缀，依次插入；基本有序时接近 `O(n)`。
- 冒泡：相邻逆序交换，一趟将极值送到端点；问趟数要看从左到右还是反向。
- 选择：每趟选极值与边界交换；比较次数通常固定 `n(n-1)/2`。
- 希尔：按 gap 分组做插入排序，逐步缩小 gap。
- 快排：选 pivot、分区、左右递归；给定每趟状态，必须确定首元素/末元素枢轴与分区细节。
- 堆排：升序一般建大根堆；根与末尾交换后缩小堆并下沉调整；建堆可 `O(n)`。
- 归并：递归拆半，再按大小稳定合并。
- LSD 基数排序：从个位到高位，每位按桶分配并**稳定收集**；若当前位相同，保持先前低位顺序。

**易错**：不是所有 `O(n log n)` 排序都稳定；“比较轮数”与“数据交换次数”不同。

## 9. 算法设计与分析基础（国网 9）

**原理**：算法设计策略是对问题结构的利用，不是背固定代码。

**怎么做**
- 分治：独立子问题 + 合并，如归并；写递推式求复杂度。
- 动态规划：最优子结构 + 重叠子问题；定义状态、转移、边界、遍历顺序，如背包、最长公共子序列。
- 贪心：局部最优直接决策，需交换论证等正确性证明，如 Kruskal、哈夫曼；**0/1 背包一般不能按单位价值贪心**。
- 回溯：搜索决策树 + 约束剪枝，如 N 皇后、排列。
- 分支限界：常用于最优化问题，使用界剪去不可能改进的分支。
- 递归与迭代：确认终止条件，考虑重复计算与栈深度。
- NP、NP-hard、NP-complete：P 是多项式时间可解；NP 是解可在多项式时间验证；NP 完全同时属于 NP 且 NP-hard。

# 第二篇 数据库系统【两者】

## 10. 基本概念、模型和体系结构（国网 10；南网数据库 1）

**原理**：数据库 DB 是数据集合，DBMS 管理数据，DBS 是数据库系统整体；外模式—模式—内模式实现数据抽象，两级映像支持逻辑/物理数据独立性。

**怎么做**：区分概念模型（ER）、逻辑模型（关系表）、物理模型（索引/页）；实体、属性、联系及 1:1、1:N、M:N；ER 转关系时 M:N 联系常单独建表。

**易错**：数据库不等于 DBMS；逻辑数据独立性 ≠ 物理数据独立性。

## 11. 关系理论、键与规范化（国网 11；南网数据库 2）

**原理**：关系是元组集合；超键能唯一确定元组，候选键是最小超键，主键是被选中的候选键；外键引用其他表的候选键/主键约束。

**怎么做**
- 函数依赖 `X→Y` 表示相同 X 的元组必须有相同 Y；属性闭包 `X+` 反复用依赖扩展，若覆盖全属性则 X 为超键。
- 1NF：属性值原子化；2NF：非主属性不部分依赖于任何候选键；3NF：对每条非平凡依赖 `X→A`，X 是超键或 A 是主属性；BCNF：每条非平凡依赖左部必须是超键。
- 分解应考虑无损连接与依赖保持，二者不是一回事。
- 关系代数：选择 σ（筛行）、投影 π（选列）、笛卡尔积 ×、连接 ⋈、并/差/交、除法（“满足所有”）。

**易错**：关系模型集合语义与 SQL 默认多重集语义不同；“主属性”指属于**某个候选键**的属性。

## 12. SQL（国网 12；南网数据库 3）

**原理**：SQL 用声明式语言描述“要什么”，查询优化器决定“如何做”。

**怎么做**
```sql
SELECT dept, COUNT(*) AS n
FROM employee
WHERE salary >= 5000
GROUP BY dept
HAVING COUNT(*) >= 3
ORDER BY n DESC;
```
- 逻辑处理顺序：`FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`（简化描述）。
- `WHERE` 过滤行，`HAVING` 过滤组；`COUNT(*)` 数行，`COUNT(col)` 不计 NULL；`DISTINCT` 去重。
- `INNER JOIN` 匹配两边；`LEFT JOIN` 保留左表未匹配行并填 NULL。
- 子查询 `IN/EXISTS`；“对所有”可用双重 `NOT EXISTS`。
- `NULL` 用 `IS NULL`，与 NULL 的一般比较结果是 UNKNOWN；三值逻辑会影响过滤。
- DDL `CREATE/ALTER/DROP`；DML `INSERT/UPDATE/DELETE`；授权 `GRANT/REVOKE`；约束 `PRIMARY KEY/FOREIGN KEY/UNIQUE/CHECK/NOT NULL`。
- 索引 B+ 树利于范围过滤、排序；联合索引常涉及最左前缀匹配，但实际取决于数据库优化器与索引机制。

**易错**：`WHERE COUNT(*)` 无效；外连接后把右表过滤条件写入 WHERE 可能意外丢掉 NULL 行。

## 13. 事务、并发控制（国网 13；南网数据库恢复等相关）

**原理**：事务 ACID：原子性、一致性、隔离性、持久性；并发不正确会引起脏读、不可重复读、幻读、丢失更新等。

**怎么做**
- 调度题：找读写/写写冲突，建优先图；图无环 ⇒ 冲突可串行化。
- 两阶段锁 2PL：加锁阶段不解锁、解锁阶段不加锁，保证冲突可串行化，但可能死锁；严格 2PL 对写锁保持至提交，减少级联回滚。
- MVCC 通过版本支持并发读；隔离级别的具体表现依 DBMS 实现而异。
- 死锁：等待图有环（单实例资源情形）表示死锁；超时、检测回滚、按序加锁可应对。

**易错**：事务一致性不是“数据没有变化”；可串行化与按提交先后串行并非同一个定义。

## 14. 备份和恢复（国网 14；南网数据库 5）

**原理**：备份是可还原的数据副本；日志（WAL）记录变化，使故障后能 REDO 已提交操作、UNDO 未提交操作（具体与恢复算法相关）。

**怎么做**：区分事务故障、系统崩溃、介质损坏；全量/增量/差异备份与日志恢复；检查点用于缩短恢复范围；`RPO` 允许损失的数据时间窗口，`RTO` 允许服务恢复时长。

**易错**：备份不等于高可用；仅复制数据库文件未必获得一致性备份。

## 15. 数据库应用系统设计与开发（国网 15；南网数据库 5）

**原理**：需求分析→概念设计 ER→逻辑关系设计→物理设计→实施→运维；查询与索引设计必须反映访问模式。

**怎么做**：从业务约束确定主/外键、唯一性、非空、索引和事务边界；辨识 N+1 查询、全表扫描、索引失效；用参数化查询避免 SQL 注入。

**易错**：为每一列建索引会增加写入与存储代价；应用校验不能替代必要的数据库约束。

## 16. 数据库安全（国网 16；南网数据库 4）

**原理**：身份认证回答“你是谁”，授权回答“能做什么”；完整性约束确保数据合法，安全控制防未授权访问与泄露。

**怎么做**：最小权限、角色 RBAC、视图和行列级控制、审计、传输/静态加密、备份加密；区分实体完整性（主键非空且唯一）、参照完整性（外键关系）、用户定义完整性（CHECK 等）。

**易错**：加密 ≠ 授权；备份文件也属于敏感数据。

# 第三篇 计算机网络【两者】

## 17. 网络体系结构、拓扑、性能（国网 17；南网网络 1）

**原理**：分层通过服务接口隐藏实现；协议是同层实体间通信规则。OSI 七层；TCP/IP 常按链路、网络、传输、应用四层教学。

**怎么做**
- 时延：传输 `L/R`，传播 `d/v`，另有处理、排队；带宽高不一定 RTT 低。
- 吞吐量由瓶颈链路与协议开销决定；时延带宽积 `RTT×带宽` 表示链路中在途数据量量级。
- 电路交换预留资源；分组交换按包共享链路；星型/总线型/环型/网状拓扑分别比较中心依赖、冲突、冗余。

**易错**：传播时延与报文长度无关，传输时延与物理距离无关。

## 18. 物理层（国网 18；南网网络 2）

**原理**：物理层负责比特在介质上传送，包括编码、调制、带宽和接口。

**怎么做**
- Nyquist 理想无噪声基带最大码元速率 `2B` Baud；若每码元 M 种状态，则上限 `2B log₂M` bit/s（理想条件）。
- Shannon 信道容量 `C=B log₂(1+S/N)` bit/s，`SNR_dB=10log₁₀(S/N)`，先把 dB 转线性。
- 双绞线/同轴/光纤比较损耗、抗干扰和带宽；单模光纤适合长距离。

**易错**：码元率 Baud 不一定等于比特率 bps。

## 19. 数据链路层（国网 19；南网网络 2）

**原理**：在相邻节点间成帧、差错检测、介质访问；以太网交换机主要依据 MAC 表转发。

**怎么做**
- CRC：数据尾部补 r 个 0，与生成多项式对应位串做模 2 除法，余数附加到末尾；接收后再除，余数 0 表示通过检测（不保证绝对无错）。
- 奇偶校验只能检出奇数个位翻转；海明码最小距离 `d_min`：最多检测 `d_min-1` 位错，最多纠正 `⌊(d_min-1)/2⌋` 位错。
- CSMA/CD 用于传统共享半双工以太网，不用于现代全双工交换以太网；Wi-Fi 用 CSMA/CA。
- ARQ：停等、回退 N 帧、选择重传；滑动窗口效率与 RTT、帧长度相关。
- VLAN 划分广播域；交换机按 MAC 地址学习，路由器跨 IP 网络转发。

**易错**：CRC 是检错不是通常意义上的纠错；交换机不等于路由器。

## 20. 网络层（国网 20；南网网络 2）

**原理**：IP 提供跨网络的尽力而为分组传送；路由选路径，转发按表选择下一跳。

**怎么做**
- IPv4 地址 32 bit，前缀 `/p` 表示网络位 p、主机位 `32-p`；常规子网可用地址 `2^(32-p)-2`（/31 点到点及 /32 例外）。
- 求网络地址：`IP AND MASK`；求广播：网络号加主机位全 1；判断同子网用掩码分别与两端地址相与。
- CIDR 最长前缀匹配：同一个目的地址匹配多条路由时选掩码最长者。
- IPv4 分片：片偏移以 **8 字节**为单位，除最后一片外有效载荷需是 8 的倍数；MTU 限制 IP 数据报尺寸。
- ARP 在本地链路解析 IPv4→MAC；ICMP 用于控制/差错通知，如 ping；NAT 通过转换地址/端口复用公网 IP。
- 路由：距离向量 Bellman–Ford 思路（如 RIP），链路状态 Dijkstra 思路（如 OSPF），BGP 为路径向量跨自治系统。

**易错**：私有地址不可直接在公网路由；默认网关用于目标不在本地子网时。

## 21. 传输层（国网 21；南网网络 2）

**原理**：端到端进程通信，端口标识应用；TCP 提供可靠、有序字节流，UDP 提供尽力而为的数据报。

**怎么做**
- TCP 三次握手：SYN、SYN+ACK、ACK；双方同步初始序号与连接状态。
- TCP 四次挥手：两方向独立关闭；主动关闭方通常进入 TIME_WAIT，等待 2MSL 以吸收延迟报文等。
- TCP 累积确认：ACK 代表下一期望字节序号；序号按**字节**计，不是报文段数。
- 流量控制：接收窗口 rwnd 防接收方被淹没；拥塞控制：cwnd 应对网络负载；有效发送窗口受二者共同限制。
- 拥塞控制：慢启动指数增长，拥塞避免近似线性增长，丢包按算法降低窗口。
- UDP 不建立连接，头部 8 字节；适合时延敏感、应用自行处理可靠性的场景。

**易错**：TCP“可靠”不是绝不丢包，而是通过确认重传等向应用提供可靠抽象。

## 22. 应用层（国网 22；南网网络 2）

**原理**：应用层定义具体业务消息格式与交互过程。

**怎么做**
- DNS 域名解析，常用 UDP/53，必要时 TCP/53；理解递归与迭代查询、缓存 TTL。
- HTTP 请求/响应与状态码：200 成功、301/302 重定向、400 客户端错误、401 未认证、403 禁止、404 未找到、500 服务端错误。
- HTTPS = HTTP over TLS，提供身份认证（依证书验证）、保密、完整性；TLS 握手与对称会话加密各司其职。
- DHCP 自动分配地址等参数，常见 DORA：Discover→Offer→Request→Ack。
- SMTP 发送邮件，POP3/IMAP 接收管理；FTP 控制/数据连接；SSH 加密远程登录。
- URL、URI、DNS 名与 IP 地址功能不同；HTTP 无状态 ≠ 应用无法实现会话（Cookie/Session/Token）。

**易错**：HTTPS 不是把 URL 隐藏得完全不可见；DNS 不是路由协议。

## 23. 网络管理与安全（国网 23；南网网络 3）

**原理**：安全三目标 CIA：机密性、完整性、可用性；身份认证、授权、审计组成访问控制链条。

**怎么做**
- 对称加密快、用于大量数据；非对称用于密钥交换/签名等；哈希不可逆摘要用于完整性校验，数字签名用私钥签、用公钥验。
- TLS 建立安全通道；证书链把公钥绑定到域名/实体；防火墙过滤策略、IDS 检测、IPS 阻断、VPN 建加密隧道。
- 常见攻击：DDoS（可用性）、中间人（认证/机密性）、重放（新鲜度）、钓鱼（社会工程）、SQL 注入（输入和查询边界）。
- SNMP 用于监控设备；网络排障按链路→IP→DNS→TCP→应用分层定位。

**易错**：散列不是加密；“有 TLS”不代表终端不会被攻破。

## 24. 无线网络、移动网络与音视频（国网 24；南网网络 3）

**原理**：无线介质共享且易受干扰，因而需要信道接入、重传、移动性管理；媒体实时传输关注吞吐、时延、抖动和丢包。

**怎么做**
- Wi-Fi IEEE 802.11 多用 CSMA/CA；隐藏终端使发送方无法仅靠侦听保证无冲突，RTS/CTS 可缓解。
- 蜂窝通信以小区复用频谱，切换保证移动连续性；4G LTE/5G NR 需掌握核心特征，如 OFDMA、MIMO、网络切片（5G）。
- 音视频：编码压缩减少码率；RTP 运载实时媒体，RTCP 提供统计反馈；缓冲可抗抖动，但会增加延迟。
- 带宽、码率、丢包与实时性通常存在权衡；“低延迟”不自动代表“画质高”。

**易错**：802.11 Wi-Fi 与蜂窝 4G/5G 属不同接入体系。

# 第四篇 操作系统【两者】

## 25. OS 概述、功能和结构（国网 25；南网 OS 1）

**原理**：OS 将硬件资源抽象为进程、虚拟地址、文件和设备，承担管理与保护；并发、共享、虚拟、异步是经典特征。

**怎么做**：区分用户态与内核态；系统调用导致受控进入内核，异常/中断触发处理；宏内核、微内核、模块化结构比较性能与隔离。

**易错**：模式切换并不一定意味着进程切换；中断常来自外设，异常常源自当前指令。

## 26. 进程线程、调度、同步、死锁（国网 26；南网 OS 2）

**原理**：进程拥有独立资源与地址空间，线程是 CPU 调度执行流（同进程线程共享大部分资源）；PCB/TCB 保存管理信息。

**怎么做**
- 进程状态：就绪、运行、阻塞，以及创建/终止；等待 I/O 从运行→阻塞，I/O 完成后阻塞→就绪。
- 调度算法：FCFS、SJF、SRTF、优先级、RR；画甘特图算周转 `完成-到达`，带权周转 `周转/服务`，等待 `周转-服务`（单段 CPU 运行的简化模型）。
- 信号量 `P(wait)` 减一/可能阻塞，`V(signal)` 加一/可能唤醒；生产者消费者需同时约束空槽、满槽和互斥。
- 临界区保证互斥，锁可能导致忙等；条件变量通常与互斥锁配合。
- 死锁四必要条件：互斥、占有且等待、不可剥夺、循环等待；银行家算法：用 Available、Allocation、Need 寻找安全序列。
- 线程上下文切换通常比进程轻，但并非零成本。

**易错**：安全状态不等于当前没有等待；有环资源分配图在多实例资源场景未必必然死锁。

## 27. 内存管理、虚拟存储（国网 27；南网 OS 2）

**原理**：程序看到的虚拟地址由 MMU 翻译成物理地址；分页消除外部碎片（仍可能有内部碎片），分段按逻辑单元划分。

**怎么做**
- 页大小 `2^k` 字节 ⇒ 虚拟地址低 k 位为页内偏移，高位为页号；物理地址 = 页框号×页大小+偏移。
- 多级页表用于节省稀疏地址空间的页表内存；TLB 缓存地址映射。
- EAT 若忽略缺页：TLB 命中率 h、TLB 查询 t、内存一次访问 m，单级页表且未命中需查页表+访数据，则 `EAT=h(t+m)+(1-h)(t+2m)`。
- 置换 FIFO、LRU、OPT：逐个访问页面、更新驻留集合并数缺页；OPT 仅作理论基准；FIFO 可能出现 Belady 异常。
- 页面置换与工作集：缺页率过高、CPU 多数时间忙于换页则为抖动。
- 连续分配：首次适应、最佳适应、最坏适应；内部碎片在已分配块内部，外部碎片散在空闲区。

**易错**：缺页意味着目标页不在内存而需异常处理，不一定表示地址非法；页大小通常按字节而非按 bit。

## 28. 文件管理（国网 28；南网 OS 3）

**原理**：文件系统将字节数据组织为文件/目录，并用 inode、目录项、块分配与缓存映射到存储介质。

**怎么做**
- 文件逻辑结构：顺序/索引等；物理分配：连续、链接、索引；分别比较随机访问和碎片。
- inode 保存元数据与数据块指针（Unix 类）；目录项做名字→文件标识映射。
- 硬链接共享 inode，不能跨文件系统；软链接保存路径并可跨文件系统，但目标删除后可能失效。
- 位图管理空闲盘块；直接+一级+二级+三级间接索引题：逐层计算每索引块能放 `块大小/指针大小` 个指针。
- FAT 表记录文件簇链；日志文件系统利用日志改进崩溃一致性。

**易错**：打开文件描述符和文件在磁盘上的 inode 不是同一对象。

## 29. 输入输出与设备管理（国网 29；南网 OS 3）

**原理**：I/O 在 CPU、设备控制器、内存间移动数据；中断让 CPU 无须持续轮询，DMA 减少大量数据搬运时 CPU 参与。

**怎么做**
- 程序查询：CPU 反复检查设备状态；中断驱动：设备就绪通知 CPU；DMA：控制器直接在设备与内存间搬运数据，CPU 负责设置/收尾。
- 磁盘访问时间≈寻道+旋转延迟+传输；调度 FCFS、SSTF、SCAN（电梯）、C-SCAN；画磁头移动路径，求移动柱面总量。
- 缓冲用于平滑速度差与批量处理；Spooling 让独占设备表现为多个任务可共享（如打印）。
- 阻塞/非阻塞针对调用是否等待；同步/异步涉及完成通知模式，两个维度不能混淆。

**易错**：DMA 不等于 CPU 完全不参与；磁盘调度时别漏掉磁头当前方向。

## 30. OS 安全与保护（国网 30）

**原理**：用用户/内核隔离、虚拟内存权限、访问控制和审计保护资源。

**怎么做**：`r/w/x` 权限、ACL、能力列表、最小权限、进程隔离、ASLR、DEP/NX；区分认证与授权；Linux 文件权限八进制如 `755=rwxr-xr-x`，目录 `x` 意味着可穿越/检索路径。

**易错**：文件可读不等于目录可列出；root 权限仍受某些安全机制约束。

# 第五篇 计算机组成与体系结构【两者】

## 31. 计算机系统、层次与性能（国网 31；南网组成 1）

**原理**：ISA 是软件与硬件接口；CPU、主存、I/O 通过总线/互联协作，冯·诺依曼机程序与数据共存。

**怎么做**
- CPU 执行时间 `CPU Time=IC×CPI/Clock Rate`；时钟频率高不必然程序快。
- 加速比 `S=T_old/T_new`；Amdahl 定律 `S=1/((1-p)+p/s)`，p 为原执行时间中可加速比例。
- 吞吐量衡量单位时间处理多少任务；响应时间衡量任务完成时长；MIPS 等指标跨指令集易误导。
- 计算机层次：数字逻辑→微体系结构→指令集 ISA→操作系统→应用语言。

**易错**：时钟周期 = 频率的倒数；CPI 与指令总数也影响总时间。

## 32. 数制编码、定点浮点、ALU（国网 32；南网组成 2、7）

**原理**：位串本身没有正负，须结合有/无符号与编码解释；补码让加减可共用二进制加法器。

**怎么做**
- 进制转换：十六进制 1 位=二进制 4 位；八进制 1 位=二进制 3 位；位运算按位计算。
- n 位无符号范围 `[0,2^n-1]`；n 位补码范围 `[-2^(n-1),2^(n-1)-1]`。
- 负数补码：绝对值二进制按位取反+1；8 位 `FEH=254-256=-2`，`F2H=-14`，`90H=-112`，`F8H=-8`。
- 补码加法溢出：**两个同号数相加结果异号**则有符号溢出；或最高符号位的进位入与进位出异或；进位标志 CF 与有符号溢出 OF 不同。
- 乘法先用真值算精确积，再检查目标寄存器范围；8 位补码 `(-14)×(-112)=1568` 溢出，`(-2)×(-8)=16` 不溢出。
- 算术右移复制符号位，逻辑右移高位补 0；左移可能丢失有效位而溢出。
- 浮点 IEEE 754 单精度 1/8/23 位（符号/阶码/尾数字段）；正规数值 `(-1)^s×(1.f)×2^(E-127)`；E=0 表示非正规或零，E=255 表示无穷或 NaN。
- 浮点加减：对阶→尾数运算→规格化→舍入→检测溢出/下溢；大数加小数可能损失精度。
- BCD 用 4 bit 编一位十进制数（有效 0000–1001）；ASCII/Unicode 表示字符，UTF-8 是变长编码。
- ALU 完成加减、逻辑与/或/非、移位与标志更新；减法可用 A+(-B) 的补码实现。

**易错**：补码与原码对负数的含义不同；十六进制 FEH 未声明位宽不能直接判负；浮点数通常不能精确表示 0.1。

## 33. 多级存储与存储芯片扩展（国网 33；南网组成 3）

**原理**：寄存器→Cache→主存→SSD/HDD，越近 CPU 往往越快、越贵、容量越小；利用时间和空间局部性。

**怎么做**
- SRAM：双稳态存储、不需要周期刷新，常用于 Cache；DRAM：电容存储、需要刷新，常用于主存；传统 ROM 非易失，PROM/EPROM/EEPROM/Flash 可有不同重写方式；SSD 常基于 NAND Flash。
- Cache 地址拆成 `tag/index/offset`；块大小 B ⇒ offset `log₂B`，组数 S ⇒ index `log₂S`，余下为 tag。
- 直接映射：主存块号 `mod 缓存行数`；组相联：`mod 组数`，在组内选择路；全相联任意位置。
- 命中率 h、命中时间 t、缺失代价 P：平均访存时间 `AMAT=t+(1-h)P`（按缺失代价定义）。
- 存储器芯片 `2K×4bit` 组成 `8K×8bit`：位扩展 `8/4=2`，字扩展 `8K/2K=4`，共 8 片。每组 2K 个地址，区间大小 `0800H`；`0B1FH` 位于 `0800H–0FFFH` 组，组起始地址 `0800H`。
- 地址线：容量 N 个独立编址单元需 `log₂N` 根（N 为 2 的幂）；数据线数量由一次读写的位宽决定。
- 大端：最高有效字节放低地址；小端：最低有效字节放低地址。
- ROM/非易失不等于一定无法写入；Cache 写策略 write-through/write-back，写分配策略需分开理解。

**易错**：K=1024；`8K×8bit` 是 8K 个 8bit 单元而不是 8K 字节乘以 8；地址范围端点均包含，大小=末地址-首地址+1。

## 34. 指令系统、寻址、CISC/RISC 与机器代码（国网 34；南网组成 4）

**原理**：机器指令由操作码与操作数字段组成；寻址方式决定操作数来源与有效地址 EA。

**怎么做**
- 立即寻址：操作数在指令内；直接寻址：地址字段=EA；间接寻址：先取内存中的地址；寄存器寻址：操作数在寄存器；寄存器间接：EA=寄存器内容；基址/变址/相对：EA=基址+位移/变址+位移/PC+位移（PC 基准以指令集定义为准）。
- 指令长度/操作码位数题：固定长度指令总位数由字段分配，操作码 k bit 最多 `2^k` 个编码；扩展操作码要考虑前缀占用。
- CISC 指令形式/长度更复杂，RISC 常强调 load/store、较规则编码和寄存器操作，但现代实现并非绝对二分。
- 汇编到机器代码：关注调用约定、寄存器、栈帧、参数传递、返回地址与局部变量。

**易错**：立即数是值，不是要再访问一次的内存地址。

## 35. CPU 功能、控制器、数据通路和流水线（国网 35；南网组成 5、6）

**原理**：数据通路（寄存器、ALU、总线）执行操作，控制器按指令产生控制信号；典型阶段取指 IF、译码 ID、执行 EX、访存 MEM、写回 WB。

**怎么做**
- 指令周期 = 取指、译码、执行等完整过程；机器周期和时钟周期不是同一概念。
- 流水线理想 k 级、n 条指令，总周期近似 `k+n-1`（各级等长、无停顿），非流水执行约 `nk` 个阶段时间单位。
- 冒险：结构冒险（硬件冲突）、数据冒险（RAW 最常见）、控制冒险（分支）；通过转发、暂停、分支预测处理。
- 中断：CPU 响应中断保存必要现场、取中断向量/进入处理程序、恢复现场；区分中断响应条件、屏蔽与优先级。
- 硬布线控制速度快但改动不便，微程序控制用微指令控制序列较灵活。

**易错**：理想流水线提高**吞吐量**，单条指令延迟不一定下降。

## 36. 总线与 I/O 系统、微机总线时序（国网 36；南网组成 6、7）

**原理**：地址总线选择位置、数据总线搬运数据、控制总线表达读写与时序；地址线通常单向（CPU 发往设备），数据线常双向。

**怎么做**
- n 条地址线最多寻址 `2^n` 个单位；m 位数据总线每次传 m bit；理论峰值带宽≈`每次传输字节数×每秒传输次数`，同步总线需考虑每传输周期数。
- 同步总线用公共时钟，异步总线用请求/应答握手；仲裁可集中或分布式。
- 程序查询、中断、DMA 比较 CPU 开销与适用数据量；存储器映射 I/O 把设备寄存器放入统一地址空间，独立编址 I/O 使用专门指令/空间。
- 微机时序：时钟周期构成总线周期/机器周期，读写操作要经历地址有效、控制有效、数据稳定和结束保持等阶段；以具体处理器时序图为准。
- SPI、I²C、UART、PCIe、USB 可按同步/异步、串行/并行、主从/点对点等特性区别。

**易错**：地址线数量决定最大可编址单元数，但实际容量还取决于每地址单位的宽度；总线理论带宽不等于有效吞吐。

## 37. 并行计算与异构计算（国网 37）

**原理**：并行性来自多核/多线程/SIMD/GPU；异构系统用不同计算单元匹配任务特征。

**怎么做**
- Flynn 分类 SISD、SIMD、MISD、MIMD；多核 CPU 常为 MIMD，向量指令体现 SIMD。
- Amdahl：串行比例限制固定规模加速比；Gustafson 从可扩展工作负载角度解释加速。
- GPU 适合大量同构并行任务，但内存传输、线程分歧、同步与显存带宽可能成瓶颈。
- 并行效率 `E=S/p`；任务并行与数据并行不同；锁、原子操作和内存一致性用于保证并发正确性。

**易错**：核数翻倍不保证时间减半；吞吐量与单请求延迟可能相反变化。

# 第六篇 软件工程【国网】

## 38. 软件工程基本概念（国网 38）

**原理**：软件工程针对复杂软件的可维护、可测试、可交付性，关注质量、成本、范围、进度和风险。

**怎么做**：区分功能性需求与非功能性质量属性（性能、可靠性、安全、可维护性等）；软件质量不等于“无 bug”，需要过程与验证。

## 39. 开发方法和过程（国网 39）

**原理**：瀑布顺序阶段清晰，迭代增量逐步交付，敏捷强调反馈，DevOps 强调开发运维协作。

**怎么做**：需求稳定/合规文档强时考虑计划驱动；需求变化快时考虑迭代；Scrum 角色、Product Backlog、Sprint、评审与回顾；CI/CD 将构建、测试和交付自动化。

**易错**：敏捷不是不做设计/文档；持续交付与持续部署不同。

## 40. 需求分析（国网 40）

**原理**：需求定义做什么而不是具体怎么编码；需可验证、可追踪、无歧义。

**怎么做**：用例描述参与者及行为，用户故事表达价值，验收标准给出可测试结果；需求分析识别干系人、边界、约束、冲突及优先级。

**易错**：“系统要快”不可测，必须转成可量化指标。

## 41. 系统设计（国网 41）

**原理**：架构划分模块及其依赖，模块化追求高内聚低耦合；接口隔离减少改动传播。

**怎么做**：区分概要设计（架构、模块、数据流、接口）与详细设计（算法、数据结构、类/函数）；UML 类图、时序图、状态图各描述静态结构、交互顺序和状态变化；常见模式如工厂、策略、观察者。

**易错**：设计模式不是目的，需回应变化点和约束。

## 42. 系统开发（国网 42）

**原理**：编码实施设计，版本控制与持续集成保障多人协作可追踪。

**怎么做**：Git 分支/合并/冲突、代码审查、静态检查、构建依赖管理、API 契约、日志和异常处理；区分单体与微服务的部署/复杂度权衡。

**易错**：微服务不必然比单体更先进；接口版本和兼容性是实施成本。

## 43. 软件测试（国网 43）

**原理**：测试是发现缺陷与建立质量证据，不是证明绝无错误；验证 verification（是否按规格做）与确认 validation（是否满足真实需要）不同。

**怎么做**
- 层次：单元、集成、系统、验收；方法：黑盒、白盒、灰盒。
- 黑盒等价类、边界值、判定表、状态迁移；白盒语句/分支/条件/路径覆盖。
- `A && B` 分支覆盖不必保证每个原子条件分别影响结果；MC/DC 要证明每个条件可独立影响判定。
- 回归测试检查改动未破坏旧行为；性能测试看响应时间、吞吐、负载/压力；测试金字塔通常底层更多。

**易错**：覆盖率 100% 不代表没有 bug；白盒不能替代业务需求验收。

## 44. 软件交付与维护（国网 44）

**原理**：交付涉及构建、配置、部署、回滚、文档、运维监控；维护分纠错、适应、完善、预防。

**怎么做**：语义化版本、蓝绿/灰度/金丝雀发布、备份与回滚策略、SLA/SLO/SLI；面对故障先止损恢复服务，再根因分析。

**易错**：部署成功 ≠ 业务成功；监控指标需与用户体验相关。

# 第七篇 信息新技术【两者/国网扩展】

## 45. 人工智能、机器学习、多模态、智能体、LLM（国网 45；南网数字化 3）

**原理**：传统 AI 范围广；机器学习从数据中拟合模型；深度学习用多层表示学习；监督/无监督/强化学习按信号不同区分。

**怎么做**
- 训练/验证/测试集用于参数学习/模型选择/独立评估；数据泄漏导致虚高成绩。
- 分类指标：准确率、精确率 `TP/(TP+FP)`、召回率 `TP/(TP+FN)`、F1 `2PR/(P+R)`；类别极不平衡时不能仅看准确率。
- 过拟合：训练好、泛化差；通过正则化、数据增强、早停等缓解；偏差方差权衡。
- 多模态识别结合图像、文本、声音等不同模态；早融合/晚融合对齐层级不同。
- Transformer 自注意力 `softmax(QKᵀ/√d_k)V`；位置编码提供序列位置信息；LLM 自回归训练常预测下一个 token。
- 智能体 Agent：规划、工具调用、记忆/状态、环境反馈的闭环；RAG 从外部检索材料注入上下文，微调改变模型参数，两者不同。
- AI 应用题区分场景目标、可用数据、评价指标、时延成本、隐私安全与幻觉风险。

**易错**：模型参数量大不保证任务正确；准确率不能代替可靠性/校准度。

## 46. 物联网、传感器、传感网络、电力物联网（国网 46）

**原理**：感知层采集物理量，网络层传输，平台/应用层存储分析并执行控制；边缘计算降低部分延迟与传输需求。

**怎么做**
- 传感器指标：灵敏度、精度、分辨率、量程、采样率；采样定理 `f_s>2f_max`（理想带限重建条件）。
- RFID/NFC、BLE、Zigbee、LoRaWAN、NB-IoT 比较距离、功耗、速率及组网方式。
- MQTT 发布订阅，CoAP 面向受限设备，HTTP 请求响应；MQTT QoS 0/1/2 分别为最多一次/至少一次/恰好一次协议交付语义（实际端到端业务语义须另看）。
- 设备身份、加密、更新、密钥管理、网关隔离是物联网安全重点。
- 电力物联网常见场景：智能电表、设备状态监测、故障告警、分布式能源接入；关注可靠性、时间同步、协议互通。

**易错**：无线低功耗通常要以速率/覆盖/频度为代价，不存在全面最优协议。

## 47. 云计算、分布式、云边协同、算力部署（国网 47；南网数字化 2）

**原理**：共享资源池按需提供算力/存储/网络；分布式系统通过多节点协作提高扩展性与容错性，但带来一致性与网络故障问题。

**怎么做**
- IaaS 提供计算/存储网络基础设施，PaaS 提供开发运行平台，SaaS 提供应用；公有云/私有云/混合云按部署关系区分。
- 虚拟机虚拟化硬件、容器隔离进程并共享宿主内核；容器镜像与实例不同。
- 分布式基础：负载均衡、复制、分片、一致性、故障转移、幂等、重试与超时。
- CAP 指发生**网络分区**时强一致性与可用性无法同时完全保证；并非任意时候“三选二”。
- 云边协同：实时控制/隐私敏感任务在边缘，重模型训练、全局聚合可在云；要权衡时延、带宽、可靠性、成本。
- 算力部署题：算资源数、单机吞吐、任务并行度、网络流量与容灾容量；避免只看 FLOPS。

**易错**：容器并非完整虚拟机；副本多不代表没有一致性问题。

## 48. 大数据、采集、处理、分析、挖掘、可视化与安全（国网 48；南网数字化 1）

**原理**：数据管道从采集→清洗→存储→加工→分析/建模→展示，需兼顾质量、规模、时效与治理。

**怎么做**
- 5V 常指 Volume、Velocity、Variety、Veracity、Value；结构化/半结构化/非结构化数据要选不同格式和处理路径。
- 批处理如 MapReduce，流处理用于低延迟持续数据；ETL 与 ELT 区别在于转换发生的阶段。
- 分布式存储常通过分区、复制实现扩展与容错；列式存储适合分析型扫描，行式存储适合事务型按行操作。
- 数据预处理：缺失、异常、重复、归一化、编码、特征选择；避免在训练测试划分前“偷看”测试集统计量。
- 数据挖掘：分类、聚类、关联规则、异常检测；关联规则支持度 `P(A∩B)`，置信度 `P(B|A)`，提升度 `P(B|A)/P(B)`。
- 数据模型/分析：回归预测连续量，分类预测标签，聚类无标签分组；按目标选 MAE/MSE/F1 等评价。
- 可视化：趋势用折线，对比用柱形，相关用散点，分布用直方图；注意截断纵轴、双轴和抽样偏差。
- 数据安全：分类分级、脱敏、访问控制、加密、审计、数据生命周期管理。

**易错**：“相关”不代表因果；数据量多不自动代表数据质量高。

# 第八篇 重点题型深化：从题干到解题过程（计算机专项）

> 本篇是对大纲知识点的**教材式扩展**，不是官方大纲原文。每个专题提供题干识别→计算/模拟步骤→边界条件，适合在会概念之后练“立刻上手做题”。

## A. 数据结构与算法专项

### A1. 时间复杂度：从循环次数到递推式

**判断流程**：① 确定输入规模 n；② 选最频繁执行的基本操作；③ 用求和/递推表示执行次数；④ 取渐近主项。若外循环从 1 到 n、内循环从 1 到 i，则比较次数 `1+2+…+n=n(n+1)/2=Θ(n²)`。若 `i*=2` 则 `Θ(log n)`；若每次 `n/=2` 同理。递归 `T(n)=T(n/2)+Θ(1)` 是 `Θ(log n)`，`T(n)=2T(n/2)+Θ(n)` 是 `Θ(n log n)`，`T(n)=T(n-1)+Θ(n)` 是 `Θ(n²)`。

**考点边界**：循环上界包含等号时影响准确次数但通常不影响数量级；问“执行多少次”需保留常数项。最坏/平均/最好不是同一个问题；快排平均好但有最坏二次情形。

### A2. 栈与队列：模拟题模板

**出栈合法性**：把待检验序列的下一个目标元素作为目标，依原入栈序列不断入栈直到栈顶等于目标，随即出栈；若当前栈顶不是目标且所有可入栈元素都已入栈，则该序列非法。对含 n 个互异元素的一入一出所有合法序列数是 Catalan 数 `C_n=(1/(n+1))·binom(2n,n)`。

**循环队列**：先问 `front` 指第一个有效元素还是前一个空位；`rear` 指最后有效元素还是下一个空位。教材常见方案中 front 指队首、rear 指下一个空位，判空 `front==rear`，队满 `(rear+1)%N==front`，长度 `(rear-front+N)%N`。若 N=8，最多存 7 个元素；如果有独立 size 计数，则可以存 8 个。

**栈指针 SP**：把“地址增长方向”和“SP 指向已用还是空”组成四格表；向低地址增长且 SP 指已用栈顶，`PUSH x: SP-=w; Mem[SP]=x`、`POP: x=Mem[SP]; SP+=w`。w 是一个栈元素的地址单位数，非必然是 1。

### A3. 树：性质、遍历、哈夫曼、BST

**树的数量题**：所有树的边数 = 节点数−1。二叉树 `n=n0+n1+n2`，边数 `n1+2n2=n−1`，相减得 `n0=n2+1`。高度 h 以层数定义时最大节点 `2^h−1`；含 n 节点的完全二叉树高度 `⌊log₂n⌋+1`（非空）。

**遍历还原题**：先序首节点或后序末节点是根；在中序中定位根，左段归左子树、右段归右子树，递归处理。要求节点标识可区分；有重复值时通常无法保证唯一重建。

**哈夫曼树题**：按权值建立最小堆，每次取出两个最小值 a、b，创建权 `a+b` 的内部节点并放回，直到只剩根；将所有合并产生的内部权值相加即可得到 WPL（叶权重非负且每步按最小合并）。前缀编码要满足一个码字不能是另一码字前缀。

**BST/AVL**：BST 搜索从根开始小往左大往右；AVL 删除/插入后，回溯检查平衡因子，按 LL、RR、LR、RL 选择单旋/双旋。问旋转结果时画局部三个节点的中序顺序，旋转不能改变中序序列。

### A4. 图：四种题目四种算法

| 关键词 | 方法 | 先做什么 | 不能错的条件 |
|---|---|---|---|
| 无权最短路径/最少边 | BFS | 起点进队，按层扩展 | visited 防重复 |
| 最短距离、非负边权 | Dijkstra | 距离初始化、每步确定最小暂定距离点 | **不能有负边** |
| 连通所有节点、总边权最小 | Prim/Kruskal | 选跨树最轻边 / 按边排序配合并查集 | 针对无向图 MST |
| 任务依赖、先后顺序 | 拓扑排序 | 统计入度，反复删除入度为 0 节点 | 只有 DAG 可全排 |

**Dijkstra 手算**：`dist[s]=0`，其他 `∞`；每次从未确定顶点里选 dist 最小者 u，再用 `dist[u]+w(u,v)` 松弛所有邻居；直到到达目标或全部处理。**关键路径**：正向求事件最早发生时刻 ve，反向求最迟 vl；活动 `(u,v)` 时差为 `vl[v]-ve[u]-duration`，零时差为关键活动（注意可能有多条关键路径）。

### A5. 查找：成功、失败 ASL 和哈希冲突

**二分查找**：明确数组有序且下标范围是否闭区间。闭区间 `low=0, high=n-1`，比较 `A[mid]`，相等成功，小则 `high=mid−1`，大则 `low=mid+1`。**失败判断通常在 `low>high` 后进行，不把这一条件判断算作关键字比较**。对于连续正整数 1…16 搜索 17，依次比较 8、12、14、15、16，5 次。

**ASL**：`ASL_success=Σ(成功查到元素 i 的比较次数×其查询概率)`；若等概率就是各比较次数平均。失败 ASL 要对所有可能的失败区间（例如各键之间及两端）按题意加权，通常不是“失败最多次数”。

**哈希题**：先算表长 m 和 `h(k)`；线性探测遇冲突查看 `(h(k)+i)%m`；成功查找次数包括目标槽之前沿探测序列比较过的槽，失败直到遇空槽（有删除标记时不能当作真正空槽）。链地址法则沿链逐个比较。

### A6. 排序：一趟结果、稳定性、比较/交换次数

- **插入**：每轮将下一个元素插进已经有序前缀；问第 k 趟就只保证前 k+1 个输入元素内部有序。
- **冒泡**：一轮完整扫相邻对并交换，最大值（升序且左→右）浮到末端；加 `flag` 才能在无交换时提前结束。
- **选择**：找最小位置与前缀下一位置交换；即使某轮未移动数值也算一趟。
- **快排**：每轮枢轴就位，**不是**整个左右分区内部有序；不同 partition 实现可能得到不同中间数组。
- **堆排**：升序通常建大根堆，堆顶与有效堆末交换，减小堆范围，向下调整。
- **归并**：将两个有序区间按双指针合并；相等时优先取左半段可保持稳定。
- **基数**：每位按桶 `0..9` 分配并按原相对先后收集；如 `[170,45,75,90,802,24,2,66]` 第一轮按个位得 `[170,90,802,2,24,45,75,66]`，第二轮按十位得 `[802,2,24,45,66,170,75,90]`，第三轮百位得 `[2,24,45,66,75,90,170,802]`。

**比较排序理论**：基于两两比较的通用排序最坏比较次数下界为 `Ω(n log n)`；基数排序突破这个下界是因为它使用按位分类而非纯比较模型。

## B. 计算机组成原理专项

### B1. 补码、加减溢出与标志位

8 位补码：`0x00..0x7F` 表示 0…127，`0x80..0xFF` 表示 −128…−1。将 8 位十六进制数转补码真值：若最高位为 1，按无符号值减 256。如 `0x90=144−256=−112`。

**有符号加法溢出**：同号相加得到异号则 OF=1，例如 `01111111(127)+00000001(1)=10000000(-128)`，发生溢出；异号相加不发生有符号溢出。**无符号进位**：看最高位是否产生进位 CF，和 OF 不同。减法 `a−b=a+(-b)`，按补码和标志位判断。

**乘法**：先求精确真值，再判断存放结果的位宽。题目若结果只写回 8 位有符号寄存器，`(-14)×(-112)=1568` 超范围，`(-2)×(-8)=16` 不超范围；截断后保留低 8 位并不能证明未溢出。

**移位**：逻辑右移补零、算术右移复制符号位；左移可能改变符号与溢出；右移负数的取整行为随具体 ISA 和运算语义变化，不要仅靠十进制口算。

### B2. 浮点数：规格化、特殊值和舍入

IEEE 754 binary32 总 32 位 = 1 符号 +8 阶码 +23 尾数字段。正常值 `(-1)^s×(1.f)×2^(E−127)`；`E=0` 代表零或非正规数，`E=255` 代表无穷/NaN。binary64 为 1+11+52，偏置 1023。

**编码题**：先将绝对值转二进制，标准化为 `1.xxx×2^e`，阶码字段=e+bias，尾数存小数点后位；最后按舍入模式处理。**运算题**：对阶→尾数加减→规格化→舍入；对阶时小量右移会损精度。区分溢出（太大）与下溢（太小难以正规表示）。

### B3. 存储体系：Cache 三种映射与 AMAT

假设主存按字节编址 32 位地址、Cache 64 KiB、块 64 B、4 路组相联：总行数 `64KiB/64B=1024`；组数 `1024/4=256=2⁸`；offset 6 位、组索引 8 位、tag 18 位。求目标地址命中：计算块号与组号，组内查 tag 与有效位。

**性能题**：若命中时间 `t=1ns`，缺失率 `m=5%`，缺失额外代价 `P=80ns`，则 `AMAT=1+0.05×80=5ns`（前提是 P 为额外缺失惩罚）。如果题给的是“缺失总时间”，不能再按此公式重复加命中时间。

**芯片扩展题**：`2K×4` 组成 `8K×8`，2 片并联扩字长、4 组串选扩字数，8 片；每个 bank 占 `0x800` 个地址。`0x0B1F` 落在 `0x0800–0x0FFF`。地址线 13 根覆盖 8K 地址，选择 bank 需要高 2 位、芯片内部需要低 11 位（假设按 8 位字节单元编址）。

### B4. 寻址方式与指令格式

遇到 `MOV R1,[R2+8]` 一类题，先按 ISA 语法判断方括号表示一次内存访问，有效地址 EA=R2+8；`MOV R1,#8` 之类的立即数写法通常把常数 8 当操作数，不取地址 8 内存。PC 相对跳转通常以 ISA 指定的 PC 基准加偏移；不要无条件把指令起始 PC 当基准。

**指令编码**：若固定长指令 16 bit，其中地址字段 12 bit，剩余可作操作码的固定字段仅 4 bit ⇒ 至多 16 种该格式的直接操作码；多格式/扩展操作码要扣除作为扩展标记的前缀编码。

### B5. CPU 流水线与总线计算

有 k 级、每级耗时 t、n 条指令，理想不停止：`T_pipe=(k+n−1)t`，非流水约 `T_nonpipe=nkt`；加速比为两者之比。真实系统还考虑数据依赖 RAW、分支清空、资源争用与时钟寄存器开销。**数据通路题**按 IF→ID→EX→MEM→WB 标明寄存器读、ALU、内存访问位置。

**总线容量**：地址线 a 根能寻址 `2^a` 个**地址单位**，若按字节编址容量就是 `2^a B`；若按字编址且每字 b 位，则最大理论数据容量 `2^a×b bit`。数据总线 d 位、每周期一次传输、总线频率 f，则理论带宽 `d×f bit/s`，实际要扣除协议开销。

## C. 操作系统专项

### C1. 调度题：给出到达/运行时间如何算

对每个进程列到达 `A`、服务时间 `S`、开始/完成 `C`、周转 `T=C−A`、带权周转 `T/S`。FCFS 按到达先后；SJF 在可调度进程中选服务时间最短且**非抢占**；SRTF 可抢占；RR 每次执行至多一个时间片后未完成就排队尾。若 CPU 空闲要在甘特图标出空洞。响应时间 = 首次获 CPU 时间−到达，和周转时间不同。

### C2. PV 操作与死锁安全序列

**生产者-消费者**：容量 N 的有界缓冲区，`empty=N, full=0, mutex=1`。生产者一般先 P(empty) 再 P(mutex) 写入，再 V(mutex)、V(full)；消费者先 P(full) 再 P(mutex) 取出，再 V(mutex)、V(empty)。若先获得 mutex 再在无空位时等待 empty，可能阻塞持有互斥锁并造成死锁。

**银行家算法**：计算 `Need=Max−Allocation`；令 `Work=Available`，反复寻找 `Need_i≤Work` 的未完成进程，假设完成后 `Work+=Allocation_i`；若所有进程都有可行完成顺序，则状态安全。安全 ≠ 当前就没有进程等待。

### C3. 分页地址、TLB、页面置换

若虚拟地址 16 bit、页大小 1 KiB=2¹⁰，页内偏移 10 位、虚拟页号 6 位。给虚拟地址 `0x12A3`：十进制 4771，页号 4，偏移 675；若页表将页 4 映射到页框 9，则物理地址 `9×1024+675=9891=0x26A3`。

**置换表格法**：横轴依次写页面访问序列，每列记录所有页框。FIFO 换最早装入的页；LRU 换最久未访问的页；OPT 换未来最晚使用或不再使用的页。命中不计缺页。遇到预装页、初始指针、局部/全局置换等条件要先注明。

**TLB EAT**：题若给 TLB 命中率 h、查 TLB 时间 t、主存时间 m、单级页表且无缺页：命中成本 `t+m`，失配成本 `t+2m`；按概率加权。若页表查找多级或 TLB lookup 与 Cache 并行，公式需根据题设重构。

### C4. 文件索引、磁盘调度

一个磁盘索引块 4 KiB、指针 4 B ⇒ 每块装 1024 个指针。文件 inode 有 10 个直接指针、1 个一级间接、1 个二级间接，最多索引 `(10+1024+1024²)` 个数据块（不考虑文件系统元数据与具体最大文件限制）。文件最大字节容量再乘 4 KiB。

磁盘调度 SCAN：先确认磁头当前磁道与运动方向，沿方向处理所有请求直到端点/最远请求（看算法定义），再折返；LOOK 与 SCAN 是否必须走物理端点不同。求总寻道长度 = 相邻移动距离绝对值之和。

## D. 计算机网络专项

### D1. CIDR 子网题完整四步

例 `192.168.10.130/26`：掩码 `255.255.255.192`，每网段 64 个地址，第三个 `/26` 网段从 `192.168.10.128` 到 `192.168.10.191`；网络地址 `.128`，广播 `.191`，传统可用主机 `.129–.190` 共 62 个。**步骤**：① 前缀找主机位；② 算步长 `256−最后非 255 的掩码字节`；③ 找 IP 所在整倍数区间；④ 网络地址/广播/主机地址分别写出。

路由选择问“匹配哪条”：先判断目标 IP 与每个网络前缀是否匹配，再选择**最长前缀**，不是选下一跳距离最短。

### D2. TCP 握手、序号与窗口

客户端发 `SYN seq=x`，服务端 `SYN+ACK seq=y ack=x+1`，客户端 `ACK ack=y+1`；SYN 和 FIN 各占一个序号。数据段若 `seq=1000`、载荷 200 字节，则对方完整收到时通常 ACK=1200。

**窗口计算**：发送方允许在途未确认数据量受 `min(rwnd,cwnd)` 限制；实际可继续发送量还要扣除当前在途未确认字节数。窗口/吞吐粗略关系 `Throughput≈Window/RTT`（有连接与路径条件限制）。

### D3. 数据链路：CRC 和交换机

CRC 题：生成多项式最高项为 r ⇒ 原数据末尾添 r 个 0，用除法逐位异或（不是普通减法）；取 r bit 余数作校验；检验时整段除同一多项式，余数为 0 则检验通过。碰撞与漏检要依据多项式分析。

交换机 MAC 学习：收到帧时先记忆**源 MAC→入端口**，目的 MAC 已知则定向转发，否则泛洪（除入端口）；广播泛洪同 VLAN 内所有其他端口。路由器不转发二层广播到别的子网（特殊中继配置另论）。

### D4. HTTP/DNS/TLS 排障顺序

地址解析失败先看本地 DNS 解析；解析正确但 TCP 连接不上，查端口、路由、防火墙和服务监听；TCP 通但 HTTPS 失败，查 TLS 握手、证书域名/时间/信任链；TLS 成功但 HTTP 4xx/5xx，再查应用参数、权限、服务端逻辑。响应码 401 是需要身份认证，403 是拒绝授权，404 是资源不存在或不暴露。

## E. 数据库专项

### E1. 候选键与范式：闭包法

设关系 `R(A,B,C)`、函数依赖 `A→B`、`B→C`。`A+={A,B,C}`，A 是候选键；`B+={B,C}` 不是超键。因为 B→C 且 B 非超键、C 非主属性，不满足 3NF，存在传递依赖 `A→B→C`。可分解为 `R1(A,B)`、`R2(B,C)`，检查无损连接和依赖保持。

**闭包操作**：初始 X+ = X；只要某条依赖左部被包含在 X+，就把右部加入；直到不能增长。找候选键时，从不出现在任何依赖右部的属性开始，再尝试最小化。

### E2. SQL 的典型坑

```sql
-- 查询每个部门中工资大于等于 5000 的员工数，至少 3 人
SELECT dept_id, COUNT(*) AS cnt
FROM employee
WHERE salary >= 5000
GROUP BY dept_id
HAVING COUNT(*) >= 3;
```

`WHERE` 在分组前筛选，`HAVING` 在分组后筛选。`COUNT(*)` 算行数、`COUNT(column)` 排除 NULL。`LEFT JOIN` 右表非匹配行填 NULL，因此 `WHERE right.col=1` 会排除这些 NULL 行（往往使查询像内连接），需要条件放 `ON` 或显式处理 NULL。

### E3. 事务与恢复

**冲突可串行化**：如果 `T1` 的某个操作先于 `T2` 对同一数据项的冲突操作，则依次加 `T1→T2` 边；构造所有冲突边后若有有向环则不是冲突可串行化。读读不冲突，读写、写读、写写冲突。

**日志恢复**：提交前遵守 WAL，数据页落盘前相应日志必须先持久化；恢复时是否 UNDO/REDO 由具体更新/日志策略决定。不是所有系统简单地“先 undo 再 redo”；题给故障、提交时刻、检查点和日志记录时应按指定策略模拟。

## F. 软件工程和新技术专项

### F1. 软件工程：题目通常问“哪个阶段处理”

需求分析明确做什么、性能与安全约束；概要设计明确体系结构/模块接口；详细设计明确算法/类/数据；编码实现；单元/集成/系统/验收测试逐级验证；维护可分纠错、适应、完善和预防。**白盒覆盖**按控制流图画判定分支，**黑盒测试**从等价类、边界值与业务规则设计案例；测试用例要有输入、预期输出和前置条件。

### F2. 新技术常见概念辨析

- **AI**：监督学习有标签，聚类典型无标签，强化学习依奖励交互；LLM 预训练、SFT、RAG、Agent 分别处理通用预测学习、任务适配、外部知识检索、工具与环境交互。
- **物联网**：感知（传感器）→传输（BLE/Zigbee/蜂窝等）→平台处理→应用；MQTT 是发布/订阅，CoAP 为受限节点设计，设备身份和证书防冒充。
- **云计算**：虚拟机有独立 guest OS，容器通常共享宿主内核；弹性伸缩不是无限资源；CAP 的限定前提是**网络分区**存在。
- **大数据**：OLTP 偏高频事务、OLAP 偏分析聚合；ETL 先转换后装载，ELT 先装载后转换；批处理/流处理按时效区别；训练集信息泄漏使评估虚高。

| 磁盘调度 | 标记当前磁道与移动方向 | SCAN/LOOK 是否走端点 |
| CIDR | IP 按前缀切分网络/主机 | /31、/32 特例 |
| TCP 确认号 | 计算已确认字节数量 | SYN/FIN 占序号 |
| CRC | 模二除法求余数 | 生成多项式次数 |
| SQL 分组 | WHERE→GROUP BY→HAVING | NULL/连接保留行 |
| 范式 | 计算属性闭包、候选键 | 主属性和超键 |
| 事务调度 | 画冲突优先图 | 是否有环 |
| 软件测试 | 先区分黑盒/白盒与测试层次 | 覆盖率不代表无 bug |
| 云/AI/大数据 | 判断概念所属层次与目标 | 真实约束和适用边界 |
