## 核心概念
FIFO 淘汰最早进入内存的页面。它维护的是装入时间，不是最近访问时间。

## 工作原理
访问的页面已在内存中即命中，队列不变。发生缺页且页框已满时，淘汰队头，再将新页面加入队尾。

## 关键公式
$$
\text{缺页率}=\frac{\text{缺页次数}}{\text{总访问次数}}
$$
本例假定初始页框为空，首次装入同样计缺页。

## 常见考法
给定引用串和页框数求缺页次数；比较 FIFO、LRU、OPT；识别 Belady 异常。

## 解题思路
3 个页框，访问 7、0、1、2、0、3：

| 访问 | 队列（最早 → 最晚） | 结果 |
| --- | --- | --- |
| 7 | 7 | 缺页 |
| 0 | 7, 0 | 缺页 |
| 1 | 7, 0, 1 | 缺页 |
| 2 | 0, 1, 2 | 缺页，淘汰 7 |
| 0 | 0, 1, 2 | 命中，顺序不变 |
| 3 | 1, 2, 3 | 缺页，淘汰 0 |

共 5 次缺页。

## 容易混淆
命中 0 后把 0 移到队尾，就把 FIFO 错算成了 LRU。增加页框数也不保证 FIFO 缺页次数一定减少。

## 关联练习
每一步同时写访问结果、被淘汰页和队列。
