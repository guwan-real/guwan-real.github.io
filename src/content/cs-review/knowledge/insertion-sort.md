## 核心概念
直接插入排序把序列分成有序前缀和未处理后缀。每趟将后缀的第一个元素插入有序前缀。

## 工作原理
初始时只有第一个元素属于有序区。从第二个元素开始，先保存待插入值，再从有序区末端向前比较，将较大的元素右移，最后填入空位。

```ts
function insertionSort(values: number[]) {
  for (let i = 1; i < values.length; i++) {
    const key = values[i];
    let j = i - 1;
    while (j >= 0 && values[j] > key) {
      values[j + 1] = values[j];
      j--;
    }
    values[j + 1] = key;
  }
  return values;
}
```

## 关键公式
最好时间复杂度为 $O(n)$，平均和最坏时间复杂度为 $O(n^2)$，额外空间为 $O(1)$。

## 常见考法
给定初始序列，求第几趟结束后的序列；判断稳定性；比较不同初始有序程度下的代价。

## 解题思路
给有序区画边界。对序列 5、2、4、6、1、3，第一趟插入 2 得到 2、5；第二趟插入 4 得到 2、4、5。后缀 6、1、3 此时保持不变。

## 容易混淆
一趟是插入一个元素，不是发生一次交换。比较时使用严格大于号才会保留相等元素的相对次序，因而是稳定排序。
